Configurer une fois

Installez sur votre PC Windows

Vous avez besoin d'un PC Windows avec Internet et un espace de plusieurs gigaoctets. Il n'y a pas encore de fichier d'installation terminé. Les étapes suivantes configurent le programme. Vous n'avez pas besoin d'être capable de programmer pour cela.

  1. 01

    Installer deux utilitaires

    Ouvrez le menu Démarrer du Windows, tapez PowerShell et ouvrez le programme. Copiez les lignes suivantes une par une et appuyez sur Entrée pour chacune d'entre elles. Attendez après chaque ligne jusqu'à ce que l'installation soit terminée.

    PowerShell
    winget install --id Python.Python.3.11 --exact --source winget
    winget install --id Gyan.FFmpeg --exact --source winget

    Python exécute LinguoAI. FFmpeg lit et écrit des vidéos. Si Windows demande une confirmation, vérifiez qu'il appartient à cette installation.

    Terminé ? Les deux installations signalent un succès ou « déjà installée ». Fermez maintenant PowerShell.

  2. 02

    Téléchargez et décompressez LinguoAI

    Téléchargez le fichier ZIP. Faites un clic droit dessus dans le dossier des téléchargements et sélectionnez « Extraire tout ». Ouvrez ensuite le dossier décompressé.

    Télécharger LinguoAI 2.2.2 ↓

    tu as raison si tu as le fichier pyproject.toml et le dossier linguoai voir.

  3. 03

    Commencez dans le bon dossier

    Dans le dossier ouvert, cliquez dans la barre d'adresse en haut. Tapez powershell et appuyez sur Entrée. Une nouvelle fenêtre s'ouvre. Copiez ces trois lignes de contrôle individuellement :

    PowerShell
    py -3.11 --version
    ffmpeg -version
    ffprobe -version

    Vous verrez Python 3.11 et deux affichages de version. S'il indique « introuvable », utilisez l'aide ci-dessous avant de continuer.

  4. 04

    Configurer LinguoAI

    Restez dans cette fenêtre. Copiez chaque ligne individuellement et appuyez sur Entrée. Attendez de pouvoir saisir à nouveau quelque chose. Les fichiers plus volumineux sont chargés la première fois.

    PowerShell
    py -3.11 -m venv .venv
    .\.venv\Scripts\python.exe -m pip install --upgrade pip
    .\.venv\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cpu
    .\.venv\Scripts\python.exe -m pip install -e ".[desktop]"

    Terminé sans message d'erreur ? La configuration est alors terminée. Vous n’en avez besoin qu’une seule fois.

  5. 05

    Programme ouvert

    Copiez cette ligne dans la même fenêtre :

    PowerShell
    .\.venv\Scripts\python.exe -m linguoai

    La fenêtre LinguoAI s'ouvre. Gardez PowerShell ouvert tant que vous utilisez LinguoAI.

Essayez-le maintenant

Votre première vidéo traduite

Tout d’abord, prenez une courte vidéo avec un langage clairement parlé, par exemple 30 secondes.

  1. Sous „Start“ sur „Datei …“ cliquez et sélectionnez votre vidéo.
  2. Celui que tu veux „Zielsprache“ choisir. La langue source peut être reconnue automatiquement.
  3. Pour ce premier test, sélectionnez « Google Translate · en ligne » et « Edge TTS · en ligne ».
  4. Ouvrez « Avancé » → « Performances ». Sous « Matériel de reconnaissance vocale », sélectionnez « CPU uniquement ». Revenez ensuite à « Démarrer ». Vous pouvez laisser les paramètres restants.
  5. Vers le haut „Verarbeitung starten“ cliquez. La première fois, LinguoAI charge également le modèle de reconnaissance vocale. Cela peut prendre du temps.
  6. À „FERTIG“ sur „Video öffnen“ cliquez. À propos „Ordner öffnen“ vous trouverez la vidéo et les deux fichiers de sous-titres.
Bon à savoir

Dans ce test simple, Google et Microsoft reçoivent du texte à traduire et à traduire. La nouvelle voix remplace tous les sons précédents, y compris la musique. Votre fichier original reste intact.

Si tu es coincé

Comment puis-je ouvrir LinguoAI la prochaine fois ?

Ouvrez à nouveau votre dossier LinguoAI extrait. Appuyez sur dans la barre d'adresse en haut powershell. Exécutez simplement la commande à partir de l’étape 5. Vous n’avez pas besoin de répéter l’installation.

"winget" n'est pas trouvé

Installez ou mettez à jour Microsoft App Installer à partir du Microsoft Store. Rouvrez ensuite le PowerShell et répétez l'étape 1.

Ouvrir les instructions Microsoft ↗
Python ou FFmpeg est introuvable

Fermez PowerShell et rouvrez-le comme à l'étape 3. Si cela ne fonctionne pas, redémarrez le PC et vérifiez à nouveau les trois lignes. Ce guide nécessite l'installation de Python 3.11.

Une commande signale une erreur

N'exécutez pas encore la ligne suivante. Vérifiez d'abord si vous êtes dans le dossier décompressé pyproject.toml et vous avez copié toute la ligne. Enregistrez le texte d'erreur exact si vous avez besoin d'aide.

Cela prend beaucoup de temps ou la vidéo ne se termine pas

Lorsque vous démarrez pour la première fois, les modèles sont téléchargés. Laissez la fenêtre ouverte et vérifiez si la progression continue. Si LinguoAI affiche une erreur, lisez le message dans le journal. Testez ensuite d’abord une vidéo plus courte.

Quatre façons d'obtenir une piste vocale

Comparez les votes

« Propre voix » peut signifier différentes choses. Ce comparatif vous aidera à faire le bon choix.

Edge TTS

Le moyen simple de démarrer avec des voix prêtes à l'emploi du catalogue Microsoft.

En ligne · Non, voix de catalogue

gTTS

Google Voice rapide via la synthèse vocale Google Translate avec code vocal.

En ligne · Non, code de langue

Piper

Sortie locale rapide avec un modèle ONNX existant ou auto-entraîné.

Locale · CPU, CUDA en option

Chatterbox V2

Adopte le caractère vocal et la manière de parler à partir d’un enregistrement court et clair.

Voix de référence · GPU recommandé

Ajouter Piper localement

Installez dans le même environnement virtuel puis chargez une voix adaptée :

.\.venv\Scripts\python.exe -m pip install -e ".[desktop,piper]"
New-Item -ItemType Directory -Force ".\Stimmen"
.\.venv\Scripts\python.exe -m piper.download_voices --download-dir ".\Stimmen" de_DE-thorsten-medium

Piper : ONNX plus JSON correspondant, identification du haut-parleur en option et débit de parole réglable.

Propre voix de référence avec Chatterbox

En raison des dépendances audio/torche, un environnement Python-3.11 dédié est recommandé :

py -3.11 -m venv .venv-chatterbox
.\.venv-chatterbox\Scripts\python.exe -m pip install --upgrade pip
.\.venv-chatterbox\Scripts\python.exe -m pip install -e ".[desktop,voice-clone]"
.\.venv-chatterbox\Scripts\python.exe -m linguoai
  • 6 à 10 secondes, une personne, peu de réverbération, pas de musique ni de bruit de fond.
  • Téléchargement du modèle d'environ 3,7 Go ; CPU est possible, mais très lent pour les vidéos plus longues.
  • L'installation native est expérimentale ; Colab ou Linux est plus fiable pour les problèmes de paquets audio.
Utilisez votre voix de manière responsable

Pour le Chatterbox, la confirmation que vous pouvez utiliser la voix est obligatoire. Utilisez votre propre enregistrement ou obtenez une autorisation explicite. La sortie contient également un filigrane PerTh intégré.

Les voix de référence contiennent des caractéristiques biométriquement sensibles. La confirmation dans LinguoAI ne remplace pas le consentement ; Le moteur Piper et le modèle vocal peuvent également avoir des licences distinctes.

Pour des processus reproductibles

Ligne de commande

Cet exemple se traduit localement par NLLB et utilise un modèle Piper. Les mêmes paramètres que dans le GUI sont disponibles pour l'automatisation.

Propre chemins de sortie et de modèle

PowerShell · Piper localement 
.\.venv\Scripts\python.exe -m linguoai `
  --input "C:\Videos\quelle.mp4" `
  --output "C:\Videos\quelle.de.mp4" `
  --language de `
  --service nllb `
  --device cpu `
  --nllb-device cpu `
  --tts-engine piper `
  --tts-device cpu `
  --piper-model "C:\Stimmen\de_DE-thorsten-medium.onnx" `
  --piper-config "C:\Stimmen\de_DE-thorsten-medium.onnx.json"

Afficher toutes les options : .\.venv\Scripts\python.exe -m linguoai --help

Répartir judicieusement la puissance de calcul

CPU et GPU ne sont pas une décision tout ou rien.

Whisper, NLLB et la voix locale peuvent être placés séparément. Vous pouvez donc commencer petit et ne mettre sur le GPU que la pièce qui en profite vraiment.

« Automatique » vérifie CUDA et revient sinon à CPU.

Important : La sélection de « GPU » n'installe pas automatiquement CUDA.
  • NLLB et Chatterbox

    Besoin d'une édition CUDA correspondante de PyTorch.

    Sélection PyTorch ↗
  • Faster-Whisper

    Nécessite en outre CUDA-12-cuBLAS et cuDNN 9 dans le chemin système.

  • Piper

    Utilise le moteur d'exécution ONNX : onnxruntime-gpu installer à la place de l'édition CPU.

En option plus rapide sur le CPU

Perruche ou Whisper ?

Perruche · 25 langues

NVIDIA Parakeet v3 reconnaît 25 langues européennes. L'adaptateur sherpa-onnx en option fonctionne localement sur le CPU avec quatre threads par défaut.

Carte modèle NVIDIA ↗

Whisper · polyvalent

Le Faster-Whisper reste la valeur par défaut avec une reconnaissance vocale automatique, une sélection de langue plus large et un traitement CPU ou GPU.

Faster-Whisper ↗

Le réglage fin primeline est spécialisé en allemand. Pour ce faire, sélectionnez le profil allemand avec un export ONNX approprié ; pour plusieurs langues européennes le profil NVIDIA. Un avantage en termes de vitesse ou de qualité n'est pas garanti sans le comparer à vos fichiers.

Mise en place d'une perruche

Installez le package facultatif et fournissez un dossier de modèle compatible. Un modèle n'est pas automatiquement téléchargé.

.\.venv\Scripts\python.exe -m pip install -e ".[parakeet]"
.\.venv\Scripts\python.exe -m linguoai --help

Utilisez le dossier modèle sherpa-onnx complet avec encodeur, décodeur, menuisier et fichier de jeton. Lors de l'export vers l'allemand, conservez également le fichier de l'encodeur externe s'il appartient au modèle.

Dans Desktop et Colab, sélectionnez le dossier de reconnaissance vocale, de profil et de modèle. Spécifiez explicitement la langue source afin que la traduction reçoive le code de langue correct. Perruche transcrite ; la traduction et la voix sélectionnées suivent ensuite.

La boîte à outils complète

Toutes les fonctions en détail.

Fichiers et commandes
  • Traitez une seule vidéo ou toutes les vidéos directement contenues dans un dossier.
  • Entrées : MP4, MKV, MOV, AVI, WEBM et M4V ; Éditions : MP4, MKV ou MOV.
  • Suggestion de sortie automatique, noms sans collision et écrasement contrôlé.
  • Avancement par dossier, étape de travail en cours, annulation et journal technique.
  • Traitement unique et par lots : téléchargez plusieurs vidéos ou entrez les chemins de fichiers MyDrive, un par ligne. Fichiers Piper et enregistrement de référence via téléchargement ou chemin MyDrive.
Transcription avec Faster-Whisper
  • Des modèles de tiny jusqu'à ce que large-v3, possèdent en outre des valeurs de modèle.
  • Détecter automatiquement la langue source ou la définir comme code de langue.
  • CPU, NVIDIA-CUDA ou sélection automatique ; int8, float16 et float32 configurables.
  • Sections audio superposées, décalages temporels réels et nettoyage des segments en double.
  • Longueurs des morceaux, chevauchement et numéro de travailleur via les options avancées ou CLI.
Traduction et protection du texte
  • NLLB-200 local, Google Translate sans clé, DeepL-SDK ou Gemini.
  • Repli facultatif uniquement après sélection explicite - sinon un seul fournisseur sera contacté.
  • Les URL, les adresses e-mail, les devises, les unités et les pourcentages sont protégés lors de la traduction.
  • Délais d'attente, répétitions limitées et cache pour des sections de texte identiques.
  • En option, Gemini corrige la transcription Whisper sans modifier les ID ou les heures de segment.
  • Posséder des modèles compatibles NLLB, révisions fixes, codes FLORES, limites de lots et de jetons.

Le modèle NLLB-600M par défaut est sous CC-BY-NC-4.0, il s'agit d'un modèle de recherche et non d'une traduction de production certifiée. Vérifiez toujours les résultats.

Timing, ton et exportation
  • Normalisez chaque clip en PCM mono 48 kHz et positionnez-le avec une précision d'échantillon.
  • Accélérez les discours trop longs dans une limite configurable.
  • Avertissement en cas d'accélération rapide ; erreur contrôlée au lieu d’une sortie incompréhensible.
  • Durée de fin exacte, métadonnées/chapitres adoptés et, si possible, flux vidéo inchangé.
  • Groupe de résultats atomiques de la nouvelle vidéo, original SRT et traduction SRT.
Où vos données sont traitées
  • NLLB · Piper · Chatterbox

    Après le téléchargement dans le terme choisi. Dans Colab, cela signifie à l'intérieur de la VM Google temporaire.

  • Google · DeepL · Gemini

    Ne recevez des sections de texte que lorsqu'elles sont sélectionnées ou en tant que solution de secours explicitement activée.

  • Edge TTS · gTTS

    Envoyez chaque réplique traduite pour être doublée au service linguistique en ligne correspondant.

  • Interface Web Gradio protégée avec mot de passe aléatoire par session.
  • Cache de modèle facultatif et copie des résultats atomiques dans Google Drive.
  • Les chemins de conduite restent dans MyDrive ; Drive n'est pas partagé en tant que dossier de téléchargement public.

Les résultats temporaires ne seront pas publiés tant que la vidéo et les deux sous-titres ne seront pas terminés. L'abandon, les tentatives limitées, les chemins de destination protégés et les clés API expurgées évitent les mauvaises surprises.

Ce que LinguoAI ne promet délibérément pas

  • La synchronisation synchrone n’est pas une synchronisation des mouvements des lèvres ; l'image n'est pas modifiée.
  • La nouvelle piste vocale remplace complètement le son original. La musique, l'ambiance et les sons ne sont actuellement pas adoptés.
  • Pas de reconnaissance des locuteurs et pas d'attribution automatique de plusieurs haut-parleurs.
  • Vérifiez toujours la transcription, la traduction, la prononciation et la similitude vocale avant de publier.
  • Colab-GPU, la durée de la session et l'achèvement des travaux volumineux ne sont pas garantis.

OPTIONNEL

Propre adresse avec Cloudflare Tunnel.

Avec SHARE_PROVIDER = "gradio" vous recevrez automatiquement un lien dynamique. Google Drive est facultatif.

Cloudflare en option

Uniquement pour votre propre adresse fixe : configurez un tunnel Cloudflare nommé avec votre propre domaine et le service http://127.0.0.1:7860. Il ne s'agit pas d'un serveur LinguoAI déployé publiquement.

Dans le Notebook, définissez SHARE_PROVIDER sur « cloudflare », remplissez CLOUDFLARE_TUNNEL_HOSTNAME avec votre propre nom d'hôte et enregistrez CLOUDFLARE_TUNNEL_TOKEN en tant que secret Colab. Ne publiez jamais de jetons.

Cloudflare : 95 Mo par téléchargement par défaut. Gradio : jusqu'à 5 Go par fichier. Pour les grandes vidéos, utilisez Google Drive. Les liens temporaires trycloudflare.com ne sont pas utilisés en raison du manque de prise en charge SSE.
