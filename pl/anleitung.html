Załóż raz

Zainstaluj na swoim komputerze Windows

Potrzebujesz komputera Windows z internetem i miejscem na kilka gigabajtów. Nie ma jeszcze gotowego pliku instalacyjnego. Poniższe kroki konfigurują program. Aby to zrobić, nie musisz umieć programować.

  1. 01

    Zainstaluj dwa narzędzia

    Otwórz menu Start Windows i wpisz PowerShell i otwórz program. Skopiuj kolejno następujące wiersze i dla każdego naciśnij klawisz Enter. Poczekaj po każdej linii, aż instalacja się zakończy.

    PowerShell
    winget install --id Python.Python.3.11 --exact --source winget
    winget install --id Gyan.FFmpeg --exact --source winget

    Python działa z LinguoAI. FFmpeg odczytuje i zapisuje filmy. Jeśli Windows poprosi o potwierdzenie, sprawdź, czy należy do tej instalacji.

    Gotowe? Obie instalacje zgłaszają sukces lub „już zainstalowane”. Teraz zamknij PowerShell.

  2. 02

    Pobierz i rozpakuj LinguoAI

    Pobierz plik ZIP. Kliknij go prawym przyciskiem myszy w folderze pobranych plików i wybierz „Wyodrębnij wszystko”. Następnie otwórz rozpakowany folder.

    Pobierz LinguoAI 2.2.2 ↓

    Masz rację, jeśli masz plik pyproject.toml i folder linguoai zobacz.

  3. 03

    Zacznij od odpowiedniego folderu

    W otwartym folderze kliknij pasek adresu u góry. Wpisz powershell i naciśnij Enter. Otworzy się nowe okno. Skopiuj te trzy linie kontrolne indywidualnie:

    PowerShell
    py -3.11 --version
    ffmpeg -version
    ffprobe -version

    Zobaczysz Python 3.11 i dwie wersje. Jeśli pojawi się komunikat „nie znaleziono”, przed kontynuowaniem skorzystaj z poniższej pomocy.

  4. 04

    Skonfiguruj LinguoAI

    Zostań w tym oknie. Skopiuj każdą linię indywidualnie i naciśnij Enter. Poczekaj, aż będziesz mógł ponownie coś wprowadzić. Większe pliki są ładowane za pierwszym razem.

    PowerShell
    py -3.11 -m venv .venv
    .\.venv\Scripts\python.exe -m pip install --upgrade pip
    .\.venv\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cpu
    .\.venv\Scripts\python.exe -m pip install -e ".[desktop]"

    Ukończono bez komunikatu o błędzie? Następnie konfiguracja jest zakończona. Potrzebujesz ich tylko raz.

  5. 05

    Otwórz program

    Skopiuj tę linię do tego samego okna:

    PowerShell
    .\.venv\Scripts\python.exe -m linguoai

    Otworzy się okno LinguoAI. Pozostaw PowerShell otwarty tak długo, jak używasz LinguoAI.

Spróbuj teraz

Twój pierwszy przetłumaczony film

Najpierw nakręć krótki film wyraźnie mówionym językiem, na przykład 30 sekund.

  1. Pod „Start“ na „Datei …“ kliknij i wybierz swój film.
  2. Ten, którego chcesz „Zielsprache“ wybierz. Język źródłowy może zostać rozpoznany automatycznie.
  3. Do pierwszego testu wybierz „Google Translate · online” i „Edge TTS · online”.
  4. Otwórz „Zaawansowane” → „Wydajność”. W sekcji „Sprzęt do rozpoznawania mowy” wybierz opcję „Tylko CPU”. Następnie wróć do „Start”. Pozostałe ustawienia możesz pozostawić.
  5. W górę „Verarbeitung starten“ kliknij. Za pierwszym razem LinguoAI ładuje także model rozpoznawania mowy. To może zająć trochę czasu.
  6. O godz „FERTIG“ na „Video öffnen“ kliknij. O „Ordner öffnen“ znajdziesz wideo i dwa pliki z napisami.
Dobrze wiedzieć

W tym prostym teście Google i Microsoft otrzymują tekst do tłumaczenia i głos. Nowy głos zastępuje wszystkie poprzednie dźwięki, w tym muzykę. Oryginalny plik pozostaje nienaruszony.

Jeśli utkniesz

Jak następnym razem otworzyć LinguoAI?

Otwórz ponownie wyodrębniony folder LinguoAI. Stuknij w pasku adresu u góry powershell. Wystarczy uruchomić polecenie z kroku 5. Nie musisz powtarzać instalacji.

„Winget” nie został znaleziony

Zainstaluj lub zaktualizuj Instalator aplikacji Microsoft ze sklepu Microsoft Store. Następnie ponownie otwórz PowerShell i powtórz krok 1.

Otwórz instrukcje Microsoft ↗
Nie znaleziono Python lub FFmpeg

Zamknij PowerShell i otwórz go ponownie, jak w kroku 3. Jeśli to nie zadziała, uruchom ponownie komputer i ponownie sprawdź trzy linie. Ten przewodnik wymaga zainstalowania Python 3.11.

Polecenie zgłasza błąd

Nie wykonuj jeszcze następnej linii. Najpierw sprawdź, czy jesteś w rozpakowanym folderze pyproject.toml i skopiowałeś całą linię. Zapisz dokładny tekst błędu, jeśli potrzebujesz pomocy.

Trwa to długo lub film się nie kończy

Przy pierwszym uruchomieniu pobierane są modele. Pozostaw okno otwarte i sprawdź, czy postęp jest kontynuowany. Jeżeli LinguoAI pokazuje błąd, przeczytaj komunikat w logu. Następnie przetestuj najpierw krótszy film.

Przejmuje charakter wokalny i sposób mówienia z krótkiego, czystego nagrania.

Głos referencyjny · Zalecany GPU

Dodaj lokalnie Piper

Zainstaluj w tym samym środowisku wirtualnym, a następnie załaduj odpowiedni głos:

.\.venv\Scripts\python.exe -m pip install -e ".[desktop,piper]"
New-Item -ItemType Directory -Force ".\Stimmen"
.\.venv\Scripts\python.exe -m piper.download_voices --download-dir ".\Stimmen" de_DE-thorsten-medium

Piper: ONNX plus pasujący JSON, opcjonalny identyfikator głośnika i regulowana szybkość mówienia.

Własny głos referencyjny z Chatterbox

Ze względu na zależność audio/latarki zalecane jest dedykowane środowisko Python-3.11:

py -3.11 -m venv .venv-chatterbox
.\.venv-chatterbox\Scripts\python.exe -m pip install --upgrade pip
.\.venv-chatterbox\Scripts\python.exe -m pip install -e ".[desktop,voice-clone]"
.\.venv-chatterbox\Scripts\python.exe -m linguoai
  • 6-10 sekund, jedna osoba, mały pogłos, brak muzyki i szumów w tle.
  • Pobranie modelu około 3,7 GB; CPU jest możliwy, ale bardzo powolny w przypadku dłuższych filmów.
  • Instalacja natywna ma charakter eksperymentalny; Colab lub Linux są bardziej niezawodne w przypadku problemów z pakietami audio.
Używaj swojego głosu w sposób odpowiedzialny

W przypadku Chatterbox potwierdzenie możliwości korzystania z głosu jest obowiązkowe. Użyj własnego nagrania lub uzyskaj wyraźną zgodę. Dane wyjściowe zawierają również osadzony znak wodny PerTh.

Głosy referencyjne zawierają funkcje wrażliwe biometrycznie. Potwierdzenie w LinguoAI nie zastępuje zgody; Silnik Piper i model głosu mogą również mieć osobne licencje.

Do powtarzalnych procesów

Linia poleceń

Ten przykład jest tłumaczony lokalnie na NLLB i wykorzystuje model Piper. Dla automatyzacji dostępne są te same ustawienia, co w GUI.

Własne ścieżki wyjściowe i modelowe

PowerShell · Piper lokalnie 
.\.venv\Scripts\python.exe -m linguoai `
  --input "C:\Videos\quelle.mp4" `
  --output "C:\Videos\quelle.de.mp4" `
  --language de `
  --service nllb `
  --device cpu `
  --nllb-device cpu `
  --tts-engine piper `
  --tts-device cpu `
  --piper-model "C:\Stimmen\de_DE-thorsten-medium.onnx" `
  --piper-config "C:\Stimmen\de_DE-thorsten-medium.onnx.json"

Zobacz wszystkie opcje: .\.venv\Scripts\python.exe -m linguoai --help

Rozsądnie rozdzielaj moc obliczeniową

CPU i GPU nie są decyzją typu „wszystko albo nic”.

Whisper, NLLB i głos lokalny można umieścić osobno. Możesz więc zacząć od małych rzeczy i umieścić w GPU tylko tę część, która naprawdę na tym zyskuje.

„Automatycznie” sprawdza CUDA, a w pozostałych przypadkach wraca do CPU.

Ważne: wybranie „GPU” nie powoduje automatycznej instalacji CUDA.
  • NLLB i Chatterbox

    Potrzebujesz pasującej wersji CUDA PyTorch.

    Wybór PyTorch ↗
  • Faster-Whisper

    Dodatkowo wymaga CUDA-12-cuBLAS i cuDNN 9 w ścieżce systemowej.

  • Piper

    Używa środowiska wykonawczego ONNX: onnxruntime-gpu zainstaluj zamiast edycji CPU.

Opcjonalnie szybszy w CPU

Papuga czy Whisper?

Papuga · 25 języków

NVIDIA Parakeet v3 rozpoznaje 25 języków europejskich. Opcjonalny adapter sherpa-onnx działa domyślnie lokalnie na CPU z czterema wątkami.

Karta modelu NVIDIA ↗

Whisper · wszechstronny

Faster-Whisper pozostaje domyślnym rozwiązaniem z automatycznym rozpoznawaniem mowy, szerszym wyborem języków i przetwarzaniem CPU lub GPU.

Faster-Whisper ↗

Pierwsza linia Fine Tune specjalizuje się w języku niemieckim. W tym celu wybierz profil niemiecki z odpowiednim eksportem ONNX; dla kilku języków europejskich profil NVIDIA. Nie można zagwarantować przewagi w szybkości ani jakości bez porównania z plikami.

Zakładanie papugi

Zainstaluj opcjonalny pakiet i udostępnij folder zgodnego modelu. Model nie jest pobierany automatycznie.

.\.venv\Scripts\python.exe -m pip install -e ".[parakeet]"
.\.venv\Scripts\python.exe -m linguoai --help

Użyj pełnego folderu modelu sherpa-onnx z koderem, dekoderem, złączem i plikiem tokena. Eksportując do języka niemieckiego, zachowaj także plik zewnętrznego enkodera, jeśli należy do modelu.

Na pulpicie i Colab wybierz folder rozpoznawania mowy, profilu i modelu. Określ wyraźnie język źródłowy, aby tłumaczenie otrzymało prawidłowy kod języka. Transkrypcja papugi; wybrane tłumaczenie i głos pojawią się później.

Kompletny zestaw narzędzi

Wszystkie funkcje szczegółowo.

Pliki i zamówienia
  • Przetwórz pojedynczy film lub wszystkie filmy zawarte bezpośrednio w folderze.
  • Wejścia: MP4, MKV, MOV, AVI, WEBM i M4V; Wersje: MP4, MKV lub MOV.
  • Automatyczna sugestia wyników, bezkolizyjne nazwy i kontrolowane nadpisywanie.
  • Postęp każdego pliku, bieżący etap pracy, anulowanie i dziennik techniczny.
  • Przetwarzanie pojedyncze i wsadowe: przesyłaj wiele filmów lub wprowadź ścieżki plików MyDrive, po jednej w wierszu. Pliki Piper i nagranie referencyjne poprzez przesłanie lub ścieżkę MyDrive.
Transkrypcja za pomocą Faster-Whisper
  • Modele tiny aż large-v3, dodatkowo własne wartości modelu.
  • Automatycznie wykryj język źródłowy lub ustaw jako kod języka.
  • CPU, NVIDIA-CUDA lub wybór automatyczny; konfigurowalne int8, float16 i float32.
  • Nakładające się sekcje audio, przesunięcia w czasie rzeczywistym i czyszczenie zduplikowanych segmentów.
  • Długości kawałków, zakładki i liczba pracowników za pomocą opcji zaawansowanych lub CLI.
Ochrona tłumaczeń i tekstów
  • NLLB-200 lokalny, Google Translate bez klucza, DeepL-SDK lub Gemini.
  • Opcjonalne rozwiązanie awaryjne tylko po wyraźnym wyborze — w przeciwnym razie skontaktujemy się tylko z jednym dostawcą.
  • URL, adresy e-mail, waluty, jednostki i procenty są chronione podczas tłumaczenia.
  • Limity czasu, ograniczone powtórzenia i pamięć podręczna dla identycznych sekcji tekstu.
  • Opcjonalnie Gemini koryguje transkrypt Whisper bez zmiany identyfikatorów segmentów i czasów.
  • Własne modele kompatybilne z NLLB, stałe wersje, kody FLORES, limity partii i tokenów.

Domyślny model NLLB-600M objęty jest licencją CC-BY-NC-4.0 i jest modelem badawczym, a nie poświadczonym tłumaczeniem produkcyjnym. Zawsze sprawdzaj wyniki.

Timing, ton i eksport
  • Normalizuj każdy klip do 48 kHz mono PCM i ustawiaj go z dokładnością do próbki.
  • Przyspiesz mowę, która jest zbyt długa, w ramach konfigurowalnego limitu.
  • Ostrzeżenie podczas szybkiego przyspieszania; kontrolowany błąd zamiast niezrozumiałego wyniku.
  • Dokładny czas zakończenia, przyjęte metadane/rozdziały i, jeśli to możliwe, niezmieniony strumień wideo.
  • Grupa wyników Atomic z nowego filmu, oryginału SRT i tłumaczenia SRT.
Gdzie przetwarzane są Twoje dane
  • NLLB · Piper · Chatterbox

    Po pobraniu w wybranym terminie. W Colab oznacza to wewnątrz tymczasowej maszyny wirtualnej Google.

  • Google · DeepL · Gemini

    Otrzymuj sekcje tekstowe tylko po wybraniu lub jako jawnie aktywowana opcja zastępcza.

  • Edge TTS · gTTS

    Wyślij każdą przetłumaczoną wskazówkę w celu jej skopiowania do odpowiedniego serwisu językowego online.

  • Chroniony interfejs sieciowy Gradio z losowym hasłem na sesję.
  • Opcjonalna pamięć podręczna modelu i niepodzielna kopia wyników w Google Drive.
  • Ścieżki dysków pozostają w MyDrive; Dysk nie jest udostępniany jako publiczny folder pobierania.

Tymczasowe wyniki nie zostaną opublikowane, dopóki wideo i oba napisy nie zostaną ukończone. Przerywanie, ograniczona liczba ponownych prób, chronione ścieżki docelowe i zredagowane klucze API pozwalają uniknąć nieprzyjemnych niespodzianek.

Czego LinguoAI celowo nie obiecuje

  • Synchroniczne wyczucie czasu nie jest synchronizacją ruchu warg; obraz nie ulega zmianie.
  • Nowa ścieżka głosowa całkowicie zastępuje oryginalny dźwięk. Muzyka, atmosfera i dźwięki nie są obecnie przyjęte.
  • Brak rozpoznawania mówców i automatycznego przypisywania wielu głośników.
  • Przed publikacją zawsze sprawdzaj transkrypcję, tłumaczenie, wymowę i podobieństwo głosu.
  • W przypadku Colab-GPU długość sesji i zakończenie dużych zadań nie są gwarantowane.

OPCJONALNIE

Własny adres z tunelem Cloudflare.

Przy SHARE_PROVIDER = "gradio" automatycznie otrzymasz link dynamiczny. Google Drive jest opcjonalny.

Opcjonalnie Cloudflare

Tylko dla własnego stałego adresu: skonfiguruj nazwany tunel Cloudflare z własną domeną i usługą http://127.0.0.1:7860. To nie jest publicznie wdrożony serwer LinguoAI.

W Notebook ustaw SHARE_PROVIDER na „cloudflare”, wypełnij CLOUDFLARE_TUNNEL_HOSTNAME własną nazwą hosta i zapisz CLOUDFLARE_TUNNEL_TOKEN jako Colab Secret. Nigdy nie publikuj tokenów.

Cloudflare: domyślnie 95MB na przesłanie. Gradio: do 5 GB na plik. W przypadku dużych filmów użyj Google Drive. Tymczasowe łącza trycloudflare.com nie są używane ze względu na brak obsługi SSE.
