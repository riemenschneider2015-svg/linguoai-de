Configurar uma vez

Instale no seu PC Windows

Você precisa de um PC Windows com internet e espaço para vários gigabytes. Ainda não há arquivo de configuração concluído. As etapas a seguir configuram o programa. Você não precisa ser capaz de programar para isso.

  1. 01

    Instale dois utilitários

    Abra o menu Iniciar Windows, digite PowerShell e abra o programa. Copie as linhas a seguir, uma de cada vez, e pressione Enter para cada uma. Aguarde após cada linha até que a instalação seja concluída.

    PowerShell
    winget install --id Python.Python.3.11 --exact --source winget
    winget install --id Gyan.FFmpeg --exact --source winget

    Python executa LinguoAI. FFmpeg lê e grava vídeos. Se Windows solicitar confirmação, verifique se pertence a esta instalação.

    Feito? Ambas as instalações relatam sucesso ou “já instaladas”. Agora feche PowerShell.

  2. 02

    Baixe e descompacte LinguoAI

    Baixe o arquivo ZIP. Clique com o botão direito na pasta de downloads e selecione “Extrair tudo”. Em seguida, abra a pasta descompactada.

    Baixe LinguoAI 2.2.2 ↓

    Você está correto se tiver o arquivo pyproject.toml e a pasta linguoai veja.

  3. 03

    Comece na pasta correta

    Na pasta aberta, clique na barra de endereço na parte superior. Tipo powershell e pressione Enter. Uma nova janela é aberta. Copie estas três linhas de verificação individualmente:

    PowerShell
    py -3.11 --version
    ffmpeg -version
    ffprobe -version

    Você verá Python 3.11 e duas versões exibidas. Se aparecer “não encontrado”, use a ajuda abaixo antes de continuar.

  4. 04

    Configurar LinguoAI

    Fique nesta janela. Copie cada linha individualmente e pressione Enter. Espere até poder inserir algo novamente. Arquivos maiores são carregados na primeira vez.

    PowerShell
    py -3.11 -m venv .venv
    .\.venv\Scripts\python.exe -m pip install --upgrade pip
    .\.venv\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cpu
    .\.venv\Scripts\python.exe -m pip install -e ".[desktop]"

    Concluído sem mensagem de erro? Então a configuração está concluída. Você só precisa deles uma vez.

  5. 05

    Abrir programa

    Copie esta linha na mesma janela:

    PowerShell
    .\.venv\Scripts\python.exe -m linguoai

    A janela LinguoAI é aberta. Mantenha PowerShell aberto enquanto você usar LinguoAI.

Experimente agora

Seu primeiro vídeo traduzido

Primeiro, faça um pequeno vídeo com linguagem falada claramente, por exemplo, 30 segundos.

  1. Abaixo „Start“ ligado „Datei …“ clique e selecione seu vídeo.
  2. Aquele que você quer „Zielsprache“ escolha. O idioma de origem pode ser reconhecido automaticamente.
  3. Para este primeiro teste, selecione “Google Translate · online” e “Edge TTS · online”.
  4. Abra “Avançado” → “Desempenho”. Em “Hardware de reconhecimento de fala”, selecione “Somente CPU”. Em seguida, volte para “Iniciar”. Você pode deixar as configurações restantes.
  5. Acima „Verarbeitung starten“ clique. Na primeira vez, LinguoAI também carrega o modelo de reconhecimento de fala. Isso pode levar algum tempo.
  6. Em „FERTIG“ ligado „Video öffnen“ clique. Sobre „Ordner öffnen“ você encontrará o vídeo e os dois arquivos de legenda.
É bom saber

Neste teste simples, Google e Microsoft recebem texto para tradução e voz. A nova voz substitui todos os sons anteriores, incluindo música. Seu arquivo original permanece intacto.

Se você ficar preso

Como abro o LinguoAI na próxima vez?

Abra a pasta LinguoAI extraída novamente. Toque na barra de endereço na parte superior powershell. Basta executar o comando da etapa 5. Você não precisa repetir a instalação.

“winget” não foi encontrado

Instale ou atualize o Microsoft App Installer na Microsoft Store. Em seguida, reabra PowerShell e repita a etapa 1.

Abra as instruções da Microsoft ↗
Python ou FFmpeg não foi encontrado

Feche PowerShell e abra-o novamente como no passo 3. Se isso não funcionar, reinicie o PC e verifique novamente as três linhas. Este guia requer a instalação do Python 3.11.

Um comando relata um erro

Não execute a próxima linha ainda. Primeiro verifique se você está na pasta descompactada pyproject.toml e você copiou a linha inteira. Salve o texto exato do erro se precisar de ajuda.

Demora muito ou o vídeo não termina

Quando você inicia pela primeira vez, os modelos são baixados. Deixe a janela aberta e verifique se o progresso continua. Se LinguoAI mostrar um erro, leia a mensagem no log. Em seguida, teste primeiro um vídeo mais curto.

Quatro maneiras de obter uma faixa de voz

Compare votos

“Própria voz” pode significar coisas diferentes. Esta comparação o ajudará a fazer a escolha certa.

Edge TTS

A maneira fácil de começar com vozes prontas do catálogo da Microsoft.

On-line · Não, voz do catálogo

gTTS

Google Voice rápido via Google Translate Text-to-Speech com código de voz.

On-line · Não, código do idioma

Piper

Saída local rápida com um modelo ONNX existente ou autotreinado.

locais · CPU, opcional CUDA

Chatterbox V2

Adota caráter vocal e maneira de falar a partir de uma gravação curta e limpa.

Voz de referência · GPU recomendado

Adicione Piper localmente

Instale no mesmo ambiente virtual e carregue uma voz adequada:

.\.venv\Scripts\python.exe -m pip install -e ".[desktop,piper]"
New-Item -ItemType Directory -Force ".\Stimmen"
.\.venv\Scripts\python.exe -m piper.download_voices --download-dir ".\Stimmen" de_DE-thorsten-medium

Piper: ONNX mais JSON correspondente, ID de alto-falante opcional e taxa de fala ajustável.

Voz de referência própria com Chatterbox

Devido às dependências de áudio/tocha, um ambiente Python-3.11 dedicado é recomendado:

py -3.11 -m venv .venv-chatterbox
.\.venv-chatterbox\Scripts\python.exe -m pip install --upgrade pip
.\.venv-chatterbox\Scripts\python.exe -m pip install -e ".[desktop,voice-clone]"
.\.venv-chatterbox\Scripts\python.exe -m linguoai
  • 6 a 10 segundos, uma pessoa, pouca reverberação, sem música ou ruído de fundo.
  • Download do modelo de aproximadamente 3,7 GB; CPU é possível, mas muito lento para vídeos mais longos.
  • A instalação nativa é experimental; Colab ou Linux é mais confiável para problemas de pacotes de áudio.
Use sua voz com responsabilidade

Para Chatterbox, a confirmação de que você pode usar a voz é obrigatória. Use sua própria gravação ou obtenha permissão explícita. A saída também contém uma marca d'água PerTh incorporada.

As vozes de referência contêm recursos biometricamente sensíveis. A confirmação em LinguoAI não substitui o consentimento; O mecanismo Piper e o modelo de voz também podem ter licenças separadas.

Distribua o poder da computação de maneira sensata

CPU e GPU não são uma decisão de tudo ou nada.

Whisper, NLLB e a voz local podem ser colocadas separadamente. Portanto, você pode começar aos poucos e colocar apenas a peça no GPU que realmente se beneficia com isso.

“Automático” verifica CUDA e, caso contrário, volta para CPU.

Importante: Selecionar “GPU” não instala automaticamente o CUDA.
  • NLLB e Chatterbox

    Precisa de uma edição CUDA correspondente do PyTorch.

    Seleção PyTorch ↗
  • Faster-Whisper

    Além disso, requer CUDA-12-cuBLAS e cuDNN 9 no caminho do sistema.

  • Piper

    Usa tempo de execução ONNX: onnxruntime-gpu instalar em vez da edição CPU.

Opcionalmente mais rápido no CPU

Periquito ou Whisper?

Periquito · 25 idiomas

NVIDIA Parakeet v3 reconhece 25 idiomas europeus. O adaptador sherpa-onnx opcional funciona localmente no CPU com quatro threads por padrão.

Placa modelo NVIDIA ↗

Whisper · versátil

Faster-Whisper continua sendo o padrão com reconhecimento automático de fala, seleção mais ampla de idioma e processamento CPU ou GPU.

Faster-Whisper ↗

A melodia primeline é especializada em alemão. Para fazer isso, selecione o perfil alemão com uma exportação ONNX adequada; para vários idiomas europeus o perfil NVIDIA. Uma vantagem de velocidade ou qualidade não é garantida sem compará-la com seus arquivos.

Configurando periquito

Instale o pacote opcional e forneça uma pasta de modelo compatível. Um modelo não é baixado automaticamente.

.\.venv\Scripts\python.exe -m pip install -e ".[parakeet]"
.\.venv\Scripts\python.exe -m linguoai --help

Use a pasta completa do modelo sherpa-onnx com codificador, decodificador, joiner e arquivo de token. Ao exportar para o alemão, guarde também o arquivo do codificador externo se ele pertencer ao modelo.

Em Desktop e Colab selecione o reconhecimento de fala, perfil e pasta de modelo. Especifique explicitamente o idioma de origem para que a tradução receba o código do idioma correto. Periquito transcrito; a tradução e a voz selecionadas seguem depois.

A caixa de ferramentas completa

Todas as funções em detalhes.

Arquivos e pedidos
  • Processe um único vídeo ou todos os vídeos contidos diretamente em uma pasta.
  • Entradas: MP4, MKV, MOV, AVI, WEBM e M4V; Edições: MP4, MKV ou MOV.
  • Sugestão automática de saída, nomes sem colisões e substituição controlada.
  • Progresso por arquivo, etapa de trabalho atual, cancelamento e registro técnico.
  • Processamento único e em lote: carregue vários vídeos ou insira caminhos de arquivo MyDrive, um por linha. Arquivos Piper e gravação de referência via upload ou caminho MyDrive.
Transcrição com Faster-Whisper
  • Modelos de tiny até large-v3, além disso, possui valores de modelo.
  • Detecte automaticamente o idioma de origem ou defina como código de idioma.
  • CPU, NVIDIA-CUDA ou seleção automática; int8, float16 e float32 configuráveis.
  • Sobreposição de seções de áudio, deslocamentos de tempo real e limpeza de segmentos duplicados.
  • Comprimentos de pedaços, sobreposição e número de trabalhadores por meio de opções avançadas ou CLI.
Tradução e proteção de texto
  • NLLB-200 local, Google Translate sem chave, DeepL-SDK ou Gemini.
  • Fallback opcional somente após seleção explícita - caso contrário, apenas um provedor será contatado.
  • URLs, endereços de e-mail, moedas, unidades e porcentagens são protegidos durante a tradução.
  • Tempos limite, repetições limitadas e cache para seções de texto idênticas.
  • Opcionalmente, Gemini corrige a transcrição Whisper sem alterar os IDs ou horários dos segmentos.
  • Modelos próprios compatíveis com NLLB, revisões fixas, códigos FLORES, limites de lote e token.

O modelo NLLB-600M padrão está sob CC-BY-NC-4.0, é um modelo de pesquisa e não uma tradução certificada de produção. Verifique sempre os resultados.

Tempo, tom e exportação
  • Normalize cada clipe para PCM mono de 48 kHz e posicione-o com precisão de amostra.
  • Acelere a fala muito longa dentro de um limite configurável.
  • Aviso ao acelerar rapidamente; erro controlado em vez de saída incompreensível.
  • Duração final exata, metadados/capítulos adotados e, se possível, fluxo de vídeo inalterado.
  • Grupo de resultados atômicos do novo vídeo, SRT original e tradução SRT.
Onde seus dados são processados
  • NLLB · Piper · Chatterbox

    Depois de baixar no termo escolhido. Em Colab, isso significa dentro da VM temporária do Google.

  • Google · DeepL · Gemini

    Receba seções de texto apenas quando selecionadas ou como um substituto ativado explicitamente.

  • Edge TTS · gTTS

    Envie cada sugestão traduzida para ser dublada para o respectivo serviço de idiomas online.

  • Interface web Gradio protegida com senha aleatória por sessão.
  • Cache de modelo opcional e cópia de resultado atômico em Google Drive.
  • Os caminhos da unidade permanecem dentro de MyDrive; O Drive não é compartilhado como uma pasta de download pública.

Os resultados temporários não serão publicados até que o vídeo e ambas as legendas estejam completos. Abortar, novas tentativas limitadas, caminhos de destino protegidos e chaves API editadas evitam surpresas desagradáveis.

O que LinguoAI deliberadamente não promete

  • O tempo síncrono não é sincronização do movimento labial; a imagem não é alterada.
  • A nova faixa de voz substitui completamente o som original. Música, atmosfera e sons não estão sendo adotados atualmente.
  • Sem reconhecimento de alto-falante e sem atribuição automática de vários alto-falantes.
  • Sempre verifique a transcrição, tradução, pronúncia e semelhança de voz antes de publicar.
  • Colab-GPU, a duração da sessão e a conclusão de trabalhos grandes não são garantidas.

OPCIONAL

Endereço próprio com Cloudflare Tunnel.

Com SHARE_PROVIDER = "gradio" você receberá automaticamente um link dinâmico. Google Drive é opcional.

Cloudflare opcional

Somente para seu próprio endereço fixo: configure um túnel Cloudflare nomeado com seu próprio domínio e o serviço http://127.0.0.1:7860. Este não é um servidor LinguoAI implementado publicamente.

No Notebook, defina SHARE_PROVIDER como "cloudflare", preencha CLOUDFLARE_TUNNEL_HOSTNAME com seu próprio nome de host e salve CLOUDFLARE_TUNNEL_TOKEN como segredo Colab. Nunca publique tokens.

Cloudflare: 95 MB por upload por padrão. Gradio: até 5 GB por arquivo. Para vídeos grandes, use Google Drive. Links temporários trycloudflare.com não são usados ​​devido à falta de suporte SSE.
